# 首版玩法

## 角色

兔兔：侏儒兔、垂耳兔、狮子兔。

毛毛：奶油、云朵、栗子、桃桃。

外观分层：主毛色、花纹色、眼睛色、头饰、颈饰、背饰、面部贴纸。

## 小窝家具

- 沙发：2 个固定座位。
- 床：可躺下，显示睡眠姿态。
- 中央地毯：3 个坐下位置。
- 食盆：兔兔补充饱食度。
- 水碗：补充少量精力。
- 绘本架：提升心情。
- 玩具球：提升心情并播放粒子效果。
- 澡盆：兔兔发起洗澡请求。
- 梳毛台：兔兔发起梳毛请求。
